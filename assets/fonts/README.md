# Font dell'interfaccia

Caratteri dell'HTML sopra la scena (Carta del cronista, menu, pannelli, fogli delle notizie). Sottoinsieme latino
in `.woff2`, presi da Google Fonts; tutti sotto **SIL Open Font License 1.1** (testo e copyright in `OFL-*.txt`).

| File | Carattere | Uso | Licenza |
|---|---|---|---|
| `Cinzel.woff2` | Cinzel (variabile, 400–900) | titoli, date, numeri dei tasti | `OFL-cinzel.txt` |
| `EBGaramond.woff2`, `EBGaramond-Italic.woff2` | EB Garamond (variabile, 400–800) | testo e pulsanti | `OFL-ebgaramond.txt` |
| `UnifrakturMaguntia.woff2` | UnifrakturMaguntia | iniziali miniate, sigilli | `OFL-unifrakturmaguntia.txt` |
| `Fondamento.woff2` | Fondamento | scrittura a mano di voci e lettere | `OFL-fondamento.txt` |
